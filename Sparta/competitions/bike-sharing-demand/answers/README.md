# 답안 제출 안내

## 코드 답안

다음 파일명으로 `code/`에 저장한다.

- `lesson1.ipynb`
- `lesson2.ipynb`
- `lesson3.ipynb`
- `lesson4.ipynb`

각 notebook은 저장소 루트에서 처음부터 끝까지 실행 가능해야 한다. 필수 출력은 Lesson의 C 문항 순서대로 배치한다.

## 글 답안

다음 파일명으로 `text/`에 저장한다.

- `lesson1.txt`
- `lesson2.txt`
- `lesson3.txt`
- `lesson4.txt`

각 답변은 `T1`, `T2`처럼 질문 번호를 유지한다. 코드 출력에서 관찰한 사실과 추가 검증이 필요한 해석을 구분한다.
