2020 1월 ~ 2024 11월 의 test 는 실제 예측을 할 때 확인하기 위한 세트이다. validation 은 어떤 모델을 선택할건지 확인하기 위함이였기 때문이다. 
따라서 우리가 정한 선형회귀 모델을 test 에 사용해서 결과를 얻어야만 한다. 

validation 에서 굳이 확인하고 test 에 적용하는 이유는 test 에 반복적으로 모델을 검정한다면 test가 test 역할을 못하고 validation 역할인 모델 선택 역할만 하게 되기 땜누이다. 

test 에서 얻은 결과를 보고 test 에 맞춰 모델을 수정하거나 하면 과적합이 일어나므로 금지다.
